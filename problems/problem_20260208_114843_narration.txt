【步骤 1】识别极限类型并初步分析

同学们，我们来看这道极限题。首先，我们要做的就是对极限的分子和分母在 x 趋近于 0 加号的时候进行一个初步的分析。对于分母，也就是 1 减去 e 的负 x 立方，当 x 趋近于 0 加号时，负 x 立方就趋近于 0，所以 e 的负 x 立方就趋近于 e 的 0 次方，也就是 1。那么整个分母就趋近于 1 减 1 等于 0。再看分子，它是一个二重积分，从 0 到 x 平方，再从 x 到根号 t。当 x 趋近于 0 加号时，外层积分的上限 x 平方会趋近于 0，所以整个积分自然也就趋近于 0。这样一看，我们发现这是一个 0 比 0 型的不定式，这就提示我们可以考虑使用洛必达法则来解决它。

--------------------------------------------------------------------------------

【步骤 2】计算分母的导数

好，既然是 0 比 0 型，那我们第一步就来计算分母的导数。设分母函数是 D（x） 等于 1 减去 e 的负 x 立方。对它求导，也就是对 x 求导，1 的导数是 0，而负 e 的负 x 立方的导数，我们需要用到链式法则。首先是对 e 的负 x 立方求导得到 e 的负 x 立方，再乘以负 x 立方对 x 的导数，也就是负 3 x 平方。所以，负的 e 的负 x 立方的导数就是负的 e 的负 x 立方乘以负 3 x 平方，结果就是 3 x 平方乘以 e 的负 x 立方。这个导数相对比较简单。

--------------------------------------------------------------------------------

【步骤 3】计算分子的导数（通过改变积分顺序）

接下来是分子的导数，这部分稍微复杂一些。我们设分子为 N（x）。仔细观察内层积分的上下限，是从 x 到根号 t。当 x 趋近于 0 加号时，对于外层积分的 t 在 0 到 x 平方之间，我们有 t 小于 x 平方，所以根号 t 就小于 x。这意味着内层积分的上限根号 t 是小于下限 x 的。根据定积分的性质，上限小于下限时，我们可以交换上下限并加一个负号。这样，整个分子 N（x） 就变成了负的从 0 到 x 平方的定积分，里面是从根号 t 到 x 对 f（t,u） du 的积分。为了方便求导，我们通常会改变这种二重积分的积分顺序。原来的积分区域是 t 从 0 到 x 平方，u 从根号 t 到 x。我们可以通过画图或者分析不等式看出，这个区域也可以描述为 u 从 0 到 x，而 t 从 0 到 u 平方。所以，分子 N（x） 就改写成了负的从 0 到 x 的定积分，里面是从 0 到 u 平方对 f（t,u） dt 的积分，再对 u 积分。现在，我们对这个新的 N（x） 求导。设里面这个关于 u 的函数是 H（u） 等于从 0 到 u 平方对 f（t,u） dt 的积分。那么 N（x） 就等于负的从 0 到 x 对 H（u） du 的积分。根据微积分基本定理，对 N（x） 求导，结果就是负的 H（x）。我们将 u 替换为 x，所以 N 撇 x 就等于负的从 0 到 x 平方对 f（t,x） dt 的积分。

--------------------------------------------------------------------------------

【步骤 4】应用洛必达法则并再次分析极限类型

好了，现在我们已经得到了分子和分母的导数。根据洛必达法则，我们现在需要计算新的极限，也就是 N 撇 x 比上 D 撇 x 在 x 趋近于 0 加号时的极限。把我们刚才算出来的导数代入进去，就是负的从 0 到 x 平方对 f（t,x） dt 的积分，再除以 3 x 平方乘以 e 的负 x 立方，求这个极限。我们再次检查一下这个极限的类型。分母 3 x 平方乘以 e 的负 x 立方，当 x 趋近于 0 加号时，仍然是趋近于 0 的。分子呢，负的从 0 到 x 平方对 f（t,x） dt 的积分，当 x 趋近于 0 加号时，积分区间从 0 到 x 平方也缩成了一个点 0，所以积分值也趋近于 0。看起来我们又回到了一个 0 比 0 型的不定式。但是别急，这次我们可以利用题目中给出的函数 f（x,y） 的连续性来简化分子。

--------------------------------------------------------------------------------

【步骤 5】利用函数连续性简化分子积分

这里是解题的关键一步，我们要利用函数 f（x,y） 的连续性。题目告诉我们 f（x,y） 是连续函数，并且 f（0,0） 等于负 1。这意味着，当点 t,x 非常接近点 0,0 的时候，f（t,x） 的值就会非常接近 f（0,0），也就是负 1。对于我们分子的积分，当 x 趋近于 0 加号时，积分变量 t 是从 0 到 x 平方，而 f（t,x） 中的第二个变量就是 x。所以，积分区域中的点 t,x 就会非常靠近 0,0。根据连续函数的性质，我们可以把积分号里面的 f（t,x） 看作是 f（0,0） 加上一个当 x 趋近于 0 时也趋近于 0 的小量。更严谨地说，我们可以把这个从 0 到 x 平方对 f（t,x） dt 的积分，写成 f（0,0） 加上一个趋近于 0 的小量 埃塔 x，再乘以积分区间的长度 x 平方。其中这个埃塔 x，当 x 趋近于 0 时是趋近于 0 的。

--------------------------------------------------------------------------------

【步骤 6】计算最终极限并验证答案

现在，我们将简化后的分子代入到洛必达法则的极限表达式中。分子变成了负的括号里是 f（0,0） 加上 埃塔 x，再乘以 x 平方。分母还是 3 x 平方乘以 e 的负 x 立方。由于 x 趋近于 0 加号，所以 x 是不等于 0 的，我们可以放心地把分子和分母中的 x 平方项约掉。这样，极限表达式就变成了负的括号里是 f（0,0） 加上 埃塔 x，再除以 3 乘以 e 的负 x 立方，求这个在 x 趋近于 0 加号时的极限。当 x 趋近于 0 加号时，埃塔 x 趋近于 0，e 的负 x 立方趋近于 1。所以，整个极限的结果就是负的 f（0,0） 除以 3 乘以 1，也就是负的 f（0,0） 除以 3。题目中明确给出了 f（0,0） 等于负 1，我们把这个值代入进去，就得到负的负 1 除以 3，最终结果就是三分之一。这个结果和我们通过洛必达法则结合连续性定理的推导是完全一致的，也符合题目中分子不为零的提示，因为我们的近似分子是 x 平方乘以 1，在 x 不为 0 时确实不为 0。所以，最终答案是三分之一。
